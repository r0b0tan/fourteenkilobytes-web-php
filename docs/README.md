# fourteenkilobytes – User Guide

The user guide explains how to set up fourteenkilobytes and how to write, publish and maintain a site with it.

- **[English](en/README.md)**
- **[Deutsch](de/README.md)**

Technical details for developers (API, tests, release process) are in the main [README](../README.md).

## Maintaining the guide

Both languages use the same file names and the same chapter structure. When you change one language, change the other in the same commit. UI labels are quoted exactly as they appear in the admin interface (`public/lang/en.json` and `public/lang/de.json`).
